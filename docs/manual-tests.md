# 手動テスト項目

実機で確認する項目のチェックリスト。**機能を追加・変更したら、この文書に追記する**（機能ごとの節）。
自動テストで拾えない「見た目・操作・OS連携」を対象にする。

---

## 認証・ログイン

- [ ] 未ログイン時にログイン画面が出る
- [ ] メールアドレスを入力→「リンクをおくる」→メールのリンクをタップ→アプリに戻ってログインできる
- [ ] 「Googleでログイン」でログインできる
- [ ] 初回ログインは表示名の登録画面が出る。登録するとメニューへ進む
- [ ] メニューのタイトルに自分の表示名が出る
- [ ] 「ログアウト」でログイン画面に戻る

## 電話帳・QR交換

- [ ] メニュー→電話帳で友達一覧が出る（いなければ「ともだちなし」）
- [ ] 「みせる」で自分のQRが電球ドットで表示される
- [ ] 「よむ」でカメラが起動し、相手のQRを読むと友達になる
- [ ] 自分のQRを読むと「じぶんのQR」になる（弾かれる）
- [ ] 交換が両方向で見える（両アカウントの電話帳に相手が出る）

## メール新規作成：文字編集

- [ ] 件名・本文の途中をタップするとカーソル（点滅する縦線）がその位置に出る
- [ ] 長押しで1文字選択、ドラッグで範囲が伸縮（反転表示）
- [ ] 範囲選択中、最下段に操作バー（コピー｜切取｜貼付｜全選択・8ドット）が出る
- [ ] OS標準の選択メニューは出ない
- [ ] コピー／切取／貼付／全選択が効く
- [ ] 変換中（未確定）の文字に下線が出る
- [ ] 折り返し位置・空行でもカーソル／タップ位置が正しい

## メール新規作成：スクロール

- [ ] 本文が3行以上で、右端に細いスクロールバーが出る（消灯と区別できる）
- [ ] 長押しなしのドラッグ＝スクロール（1行ずつ）
- [ ] 長押し後のドラッグ＝範囲選択
- [ ] 選択中に表示領域の上端/下端までドラッグすると1行ずつ自動スクロール
- [ ] カーソルが表示外に出たら見える位置まで自動で行送り

## メール新規作成：キーボード（入力モード）

- [ ] 欄をタップ→キーボードが出ると、見出し＋入力欄（拡大）＋操作バーがキーボードの上に収まる（下に隠れない）
- [ ] 電球の大きさは変わらない（画面全体が縮小しない）
- [ ] 戻るボタンでキーボードを閉じ→再タップでまたキーボードが出る（5回繰り返して毎回出る）
- [ ] キーボードを閉じると通常レイアウトに戻る

## メール新規作成：ポップアップ

- [ ] OKボタンと本文欄が重なる位置でOKを押しても、**10回中1回も本文欄が開かない**（最前面が独占）
- [ ] ポップアップのOK以外の場所をタップしても背後のフォームが反応しない
- [ ] 入力不備（宛先なし）で送信→案内ポップアップ→OKで宛先選択に進む
- [ ] 入力不備（本文も写真もなし）で送信→案内→OKで本文欄にフォーカス

## 写真添付

- [ ] 「しゃしん」で「カメラでとる／しゃしんをえらぶ」の2択（カメラが上）
- [ ] 「カメラでとる」で撮影→添付される
- [ ] 「しゃしんをえらぶ」で写真専用ピッカーが開く（全体アクセス許可の確認は出ない）
- [ ] 添付した写真つきで送信できる（送信時にガラケー加工される）

## 送信とその信頼性

- [ ] 宛先・本文を入れて送信→「そうしん中…」→「そうしんしました」（自動で消える）→メールメニューへ
- [ ] 送信後、そうしんBOXに1件だけ増える（二重に増えない）
- [ ] **送信失敗（Wi-Fiとモバイルデータを両方オフにする）**→「そうしんできませんでした」＋OK
- [ ] 失敗後、OKで閉じると宛先・件名・本文・写真が残ったまま新規作成に留まる
- [ ] 両方の通信をオンに戻して再送→送信できる
- [ ] （長期）数日ぶりにアプリを開いて送信→失効していても送れる（更新して自動再送）

## 送信BOX

- [ ] 送信済みが新しい順・1件2行（宛先名＋日時／件名か本文冒頭）で並ぶ
- [ ] 日時は今日=HH:MM、それ以前=MM/DD
- [ ] 4件以上で「◀ 1/N ▶」のページ送り（1ページ3件）
- [ ] 行タップで詳細（To:相手名、日時 YYYY/MM/DD HH:MM、件名、本文）
- [ ] 本文が長いとき、詳細でドラッグしてスクロールできる
- [ ] 相手の開封を連想させる表示が一切ない
